# Net-zero potential of Dominican social housing — models, data and code

Supporting data and code for:

> Mané Nina, M. N., García Kerdan, I. *Assessing the Net-Zero Potential of Caribbean Social Housing with Rooftop Solar, Shared Storage, and Efficiency Retrofits.* Submitted to *Energy Efficiency First* (2026).

The package lets anyone rerun every number in the paper. It covers a 42-apartment social-housing development in the Dominican Republic, modelled in three climates: Montecristi (MC), Santo Domingo Este (SD) and Santiago (ST).

## Contents

| Folder | What it holds |
|---|---|
| `inputs/energyplus/validation_package/models/` | 15 original EnergyPlus 23.1 models: baseline E0, passive retrofit E1, active retrofit E2, and the night-ventilation variants (`_VENT`) |
| `inputs/energyplus/validation_package/climate/` | TMYx weather files for the three stations ([climate.onebuilding.org](https://climate.onebuilding.org)) |
| `inputs/energyplus/validation_package/hourly_profiles/` | Hourly loads from the original models |
| `inputs/energyplus/variants_v25/` | 21 models used in the paper, generated by `scripts/make_variants.py` (see below) |
| `inputs/energyplus/hourly_profiles_v25/` | Hourly loads from the 24 simulations behind the paper's results |
| `scripts/` | Python code (see workflow) |
| `results/results.json` | Energy, dispatch, billing, outage and finance results for every site and step |
| `results/derived.json` | Incremental cash flows, switching values, sensitivity, cost of conserved energy, LCOE and resilience cost |

### Model variants (`variants_v25`)

- `*_film`: E1/E2 with the glazing modelled as a solar-control film on the existing single glass. SHGC is 0.30 and U stays at 5.8 W/m²K.
- `*_VENT_film`: the same change applied to the night-ventilation models.
- `*_night`: cooling available only from 21:00 to 07:00 (the night-only service level). The E1/E2 night models also include the film change.

## Workflow

```bash
pip install -r requirements.txt

# 1 (optional) rebuild the model variants from the original models
python scripts/make_variants.py

# 2 (optional) rerun the 24 EnergyPlus simulations (requires EnergyPlus 23.1.0)
export ENERGYPLUS_DIR=/path/to/EnergyPlus-23.1.0
python scripts/run_simulations.py

# 3 PV, battery dispatch, outages, tariffs and finance  -> results/results.json
python scripts/pipeline.py

# 4 derived economic indicators                         -> results/derived.json
python scripts/analysis.py
```

Steps 3–4 take a few minutes and use the stored hourly profiles. Steps 1–2 regenerate those profiles; their output is byte-identical to the files supplied.

- `scripts/run_all.py` is the original workflow (PV model, battery dispatch, outage test, flat-tariff billing). `pipeline.py` reuses its functions.
- `run_energyplus.py` runs one model and writes the hourly profile.

## Main assumptions

All assumptions are listed in the paper (Table 2 and Annex). The main ones:

- **Building model:** ideal-loads cooling with a 60% RH humidistat. COP is 2.8 for E0/E1 and 4.0 for E2.
- **PV:** 101 kWp horizontal array (Canadian Solar CS1U-400MS), modelled with pvlib.
- **Battery:** load-following dispatch, sized at the knee of the self-sufficiency curve.
- **Tariffs:** SIE-044-2026-TF. The central case is BTD; BTS-1 is the alternative.
- **Surplus energy:** valued at the SIE-064-2022-TF reference prices.
- **Finance:** 8% real discount rate over 25 years; RD$60.50 per US$; grid emission factor 0.6277 t CO2/MWh.
